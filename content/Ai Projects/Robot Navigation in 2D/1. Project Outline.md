# 🧠 2D Point-Robot Navigator 
This project is not simple classification problem, but it's actually a spatial reasoning + temporal planning problem.
## Problem Statement
Learn a policy π that maps robot sensing to actions that reach a goal without collisions in cluttered 2D worlds.
All the project code can be found here [Github Code](https://github.com/oalahurikar/Robot-Navigation)



### Training Data Quality

What your robot KNOWS (21 features):
- 3×3 local perception (where obstacles are nearby)
- Last 3 actions (where it's been)
What your robot DOESN'T KNOW:
- ❌ Goal location
- ❌ Global environment layout
- ❌ Optimal path direction
- ❌ Distance to goal
